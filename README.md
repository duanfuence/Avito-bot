# Avito Market Scanner

Система мониторинга объявлений Авито, анализа рыночных цен и уведомлений о выгодных предложениях в Telegram.

Текущий этап: **1 — проверка реализуемости.**

- [docs/01-feasibility.md](docs/01-feasibility.md) — техническая оценка и архитектура.
- [docs/02-windows-test.md](docs/02-windows-test.md) — **как запустить первый тест на Windows** (пошагово).
- `probe/` — пробный скрипт: проверяет, какие данные Авито реально доступны с вашего компьютера.
  - `start_windows.bat` — запуск двойным щелчком.
  - `avito_probe.py` — сам скрипт (1 запрос по ссылке или разбор сохранённой страницы).
  - `tests/` — самопроверка без интернета (на синтетической, не настоящей странице).

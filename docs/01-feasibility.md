## 1. Как можно получить данные Авито

| # | Способ | Разрешено Авито? | Данные | Надёжность | Стоимость |
|---|--------|------------------|--------|------------|-----------|
| A | **Официальный API** (developers.avito.ru) | Да | Только **ваши** объявления, чаты, статистика, автозагрузка | Высокая | 0 ₽ |
| B | **Сохранённые поиски Авито + уведомления** | Да | Новые объявления по вашему поиску (push в приложении; e-mail — нужно проверить, есть ли у вас эта настройка) | Средняя | 0 ₽ |
| C | **Страница, сохранённая из браузера** (Ctrl+S → загрузка в систему) | Серая зона: данные извлекаются из страницы, которую вы сами открыли | Всё, что видно в выдаче | Высокая, но вручную | 0 ₽ |
| D | **Периодическое автоматическое чтение страницы поиска** (то, что вы описали) | **Нет.** Пользовательское соглашение Авито (по найденным цитатам) запрещает извлекать материалы «ручным или автоматическим способом» без разрешения | Всё, что видно в выдаче, + карточки | Средняя/низкая: Авито блокирует частые запросы, особенно с серверных IP | 0–500 ₽/мес |
| E | Платные сторонние парсеры (Apify и т. п., ~$4 за 1000 объявлений) | Нет; часть из них прямо заявляет обход защиты | Полные | Средняя | $10–50/мес |

### Ключевые выводы

1. **Официального способа получать чужие объявления по поисковой ссылке нет.** Официальный API Авито предназначен для продавцов: управлять своими объявлениями, сообщениями и статистикой. Публичного API поиска по рынку в нём нет. (Проверить это по первоисточнику из моей среды не удалось: avito.ru и developers.avito.ru здесь заблокированы. Вывод основан на сторонних описаниях API и моих знаниях. Можете открыть developers.avito.ru/api-catalog и проверить сами.)
2. **Вариант D (ваша исходная задумка) технически реалистичен, но нарушает правила Авито.** Это гражданско-правовой риск: блокировка IP, теоретически претензии. Уголовного состава в личном некоммерческом мониторинге цен нет, но решение принимаете вы. Я не буду обходить CAPTCHA, блокировки, ротировать IP и маскировать бота. Значит, при блокировке система просто будет ждать и сообщать о проблеме.
3. **Вариант E** противоречит вашему же требованию не обходить защитные механизмы. Не рекомендую.
4. **Архитектура не зависит от источника данных.** Аналитика, база, Telegram и панель управления одинаковы для вариантов B, C и D. Источник — это сменный модуль («адаптер»). Можно начать с C и при необходимости перейти на D, или наоборот.

## 2. Реалистичные ограничения (при любом варианте)

- **Поисковая выдача показывает ~50 объявлений на страницу.** Полный обход рынка «iPhone 15 по всей России» — это десятки страниц, то есть десятки запросов. Для варианта D разумно мониторить **первые 1–3 страницы с сортировкой «по дате»**: так ловятся новые объявления, а статистика копится постепенно.
- **Безопасная частота для D:** ориентир 1 запрос в 10–15 минут на поиск, с паузами между запросами. Точнее покажет только опыт: стабильность у Авито не гарантирована.
- **Где запускать D:** с домашнего IP (свой компьютер или мини-ПК/Raspberry Pi) вероятность блокировки заметно ниже, чем с облачного сервера. Мой облачный контейнер получает отказ даже на соединение, так что облако — плохой выбор для сбора данных.
- **Характеристики (память, состояние, «битый») извлекаются из текста** заголовка и описания эвристиками. Ошибки неизбежны, поэтому оценка «надёжность данных» будет отдельной метрикой, как вы и просили.
- **Цена снятого объявления не равна цене сделки.** Это будет явно указано в интерфейсе.
- **Telegram:** Bot API должен быть доступен с машины, где работает бот. Если в вашей сети Telegram ограничен, это нужно проверить отдельно (пробный скрипт этапа 4).

## 3. Рекомендуемая архитектура (минимум затрат)

```
 [Источник данных — сменный адаптер]
   C: HTML-файл из браузера ──┐
   D: страница поиска (1 запрос / 10–15 мин, стоп при блокировке) ──┤
                              ▼
                  Парсер → Нормализация (модель, память, состояние, риски)
                              ▼
                  SQLite: listings, price_history, observations, searches
                              ▼
            Аналитика: медиана/квартили/IQR-выбросы по группе сопоставимых
            (модель + память + состояние), оценки «цена» и «надёжность»
                    ▼                         ▼
          Telegram-бот (aiogram)     Веб-панель (FastAPI + HTML/JS, графики)
          уведомления + команды      таблица, фильтры, графики, CSV/Excel
```

Всё работает **одним процессом Python** со встроенным планировщиком (APScheduler).

### Почему именно эти технологии

| Выбор | Почему | Почему не альтернатива |
|-------|--------|------------------------|
| **Python 3.11+** | Лучшие библиотеки для разбора HTML, статистики и Telegram; прост для новичка | — |
| **SQLite** | Один файл, без сервера; бэкап — копия файла; тянет миллионы строк, а у нас тысячи | PostgreSQL — отдельный сервер, администрирование, а выигрыша на одном пользователе нет. Переход позже возможен (через SQLAlchemy) |
| **Веб-панель вместо Google Sheets** | Нет квот Google API, мгновенные фильтры и графики, история цен, избранное с заметками, работает без интернета-посредника | Google Sheets удобен, но: лимиты API, сложная настройка сервисного аккаунта, медленная перерисовка, нет нормальной связи «объявление → история цен». **Экспорт в Excel/CSV будет**, синхронизацию с Sheets можно добавить позже |
| **aiogram 3** | Современная асинхронная библиотека для Telegram, хорошо работает вместе с FastAPI в одном процессе | — |
| **APScheduler** внутри приложения | Не нужен cron/systemd-таймер; задачи переживают перезапуск (хранятся в БД) | Celery+Redis — избыточно |
| **`.env`-файл** | Токены не попадают в код и git | — |

### Где запускать и сколько стоит

| Вариант | Стоимость | Комментарий |
|---------|-----------|-------------|
| Ваш компьютер (когда включён) | 0 ₽ | Хорошо для старта и варианта C |
| Мини-ПК / Raspberry Pi / старый ноутбук дома 24/7 | 0 ₽ + электричество (~50–100 ₽/мес) | **Рекомендую для варианта D**: домашний IP |
| Российский VPS (1 vCPU, 1 ГБ) | ~200–500 ₽/мес | Подходит для бота и панели, но **не** для сбора с Авито (серверные IP блокируются чаще) |

Надёжность с первого дня: логи в файл с ротацией; повтор при сетевых сбоях (не при блокировке); при блокировке — пауза с увеличением интервала и уведомление вам в Telegram; ежедневная копия БД (хранятся последние 14); миграции схемы без потери истории.

## 4. Минимальный рабочий прототип (MVP) — что запускаем первым

**MVP-1 (этапы 2–3, ~1 итерация):**
1. Вы добавляете поиск: название + ссылка + группа сравнения.
2. Источник: HTML-файл (вариант C) **и/или** один запрос по ссылке (вариант D) — в зависимости от вашего решения.
3. Объявления сохраняются в SQLite без дублей; цены пишутся в историю.
4. Считаются медиана, среднее, Q1/Q3, выбросы и отклонения в ₽ и %; ценовая оценка 0–100 и список рисков с объяснением.
5. Выгрузка в Excel с цветовой индикацией (зелёный, жёлтый, красный, серый — «мало данных»).

**MVP-2 (этапы 4–5):** Telegram-уведомления и команды, планировщик, бэкапы.
**MVP-3 (этап 6):** веб-панель с графиками, избранным и сравнением моделей.

## 5. Что нужно от вас сейчас

1. **Запустить пробный скрипт** (инструкция ниже) со своей ссылкой поиска и прислать мне содержимое `probe_output/report.txt`. Он покажет, отдаёт ли Авито страницу вашему компьютеру и какие поля реально извлекаются.
2. **Выбрать способ получения данных:**
   - **C** — полностью в рамках «я сам открыл страницу»: без автоматического опроса и без мгновенных уведомлений;
   - **D** — автоматический опрос с низкой частотой с домашнего компьютера, с остановкой при блокировке. Вы осознанно принимаете, что это противоречит пользовательскому соглашению Авито;
   - **C + D** — оба адаптера; переключение в настройках (мой вариант по умолчанию: он не привязывает систему к одному источнику).

### Как запустить пробный скрипт (Windows / macOS / Linux)

1. Установите Python 3.11+ с python.org (на Windows отметьте галочку «Add Python to PATH»).
2. Скачайте проект (кнопка Code → Download ZIP на GitHub) и распакуйте.
3. Откройте терминал в папке `probe` и выполните:

```bash
python -m venv .venv
# Windows:  .venv\Scripts\activate
# macOS/Linux:  source .venv/bin/activate
pip install -r requirements.txt

# Вариант D — один запрос по ссылке (кавычки обязательны):
python avito_probe.py "https://www.avito.ru/...ваша ссылка поиска..."

# Вариант C — страница, сохранённая из браузера (Ctrl+S → «Веб-страница целиком»):
python avito_probe.py --file "путь/к/странице.html"
```

4. Пришлите мне текст из `probe_output/report.txt`. Если объявлений найдено 0, приложите ещё начало `probe_output/page.html`: по нему я поправлю парсер под текущую вёрстку.

Скрипт делает ровно один запрос. При ответе «доступ ограничен» или CAPTCHA он останавливается и ничего не повторяет.

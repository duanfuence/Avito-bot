# Первый тест на Windows 10 / 11 — пошаговая инструкция

Цель: проверить, какие данные Авито доступны с **вашего** компьютера.
Время: 15–20 минут. Ничего, кроме Python, устанавливать не нужно.

Что делает скрипт:
- По ссылке он отправляет **один** запрос к странице поиска. Повторить запрос по ссылке можно не раньше чем через 5 минут.
- В режиме файла к Авито он не обращается вообще.
- Cookies, логины и пароли не использует. CAPTCHA и блокировки не обходит: при них сразу останавливается.
- В результатах нет ваших личных данных и данных аккаунта. Телефоны и e-mail из описаний скрыты.

---

## Шаг 1. Установить Python (один раз)

1. Откройте https://www.python.org/downloads/windows/
2. Найдите строку **Python 3.13.x** (любая последняя 3.13) и нажмите **Download Windows installer (64-bit)**.
3. Запустите скачанный файл `python-3.13.x-amd64.exe`.
4. **Важно:** внизу первого окна поставьте галочку **«Add python.exe to PATH»**.
5. Нажмите **Install Now** и дождитесь надписи **Setup was successful**. Нажмите **Close**.

**Проверка:** нажмите `Win + R`, введите `cmd`, нажмите Enter. В чёрном окне введите и нажмите Enter:

```
py --version
```

Должно появиться: `Python 3.13.…`. Если пишет «не является внутренней или внешней командой», перезагрузите компьютер и проверьте ещё раз. Если не помогло, запустите установщик снова и проверьте галочку из пункта 4.

## Шаг 2. Скачать проект

1. Откройте в браузере (войдите в GitHub, если попросит):
   https://github.com/duanfuence/Avito-bot/archive/refs/heads/stage1-feasibility.zip
2. Скачается файл `Avito-bot-stage1-feasibility.zip`.
3. Откройте папку «Загрузки», нажмите на архив **правой** кнопкой → **Извлечь все…** → **Извлечь**.
4. Откроется папка `Avito-bot-stage1-feasibility`, внутри неё ещё одна с тем же именем. Зайдите в неё, затем в папку **`probe`**.

В папке `probe` должны быть: `avito_probe.py`, `requirements.txt`, `start_windows.bat`, папка `tests`.

## Шаг 3. Скопировать ссылку на поиск

1. Откройте avito.ru в браузере и настройте поиск: например, «iPhone 15», регион, фильтры.
2. Для теста лучше выбрать сортировку **«По дате»**.
3. Щёлкните по адресной строке браузера (адрес выделится) и нажмите `Ctrl + C`.

## Шаг 4. Тест А — один запрос по ссылке

1. В папке `probe` дважды щёлкните **`start_windows.bat`**.
   - Если Windows покажет «Windows защитила ваш компьютер», нажмите **Подробнее** → **Выполнить в любом случае**. Если появится «Предупреждение системы безопасности», нажмите **Запустить**.
2. При первом запуске появится «Первый запуск: создаю окружение Python…». Это займёт до минуты, нужен интернет.
3. Когда появится строка **`Ссылка или файл, затем Enter:`**, щёлкните **правой** кнопкой мыши внутри окна (или нажмите `Ctrl + V`): ссылка вставится. Нажмите **Enter**.
4. Дождитесь результата (см. «Что вы должны увидеть» ниже) и нажмите любую клавишу, чтобы закрыть окно.

## Шаг 5. Тест Б — страница, сохранённая из браузера

Этот тест покажет, работает ли система, даже если Авито блокирует запросы скрипта.

1. Лучше открыть Авито в окне **инкогнито** (`Ctrl + Shift + N`): тогда на сохранённой странице точно не будет данных вашего аккаунта. Откройте ту же ссылку поиска.
2. Прокрутите страницу до конца, чтобы загрузились все объявления.
3. Нажмите `Ctrl + S`. Тип файла: **«Веб-страница полностью»**. Сохраните, например, на Рабочий стол.
4. Снова дважды щёлкните `start_windows.bat`.
5. На вопрос **`Ссылка или файл`** **перетащите мышкой** сохранённый файл `.html` в чёрное окно (путь вставится сам) и нажмите **Enter**.

## Где результаты

После успешного запуска папка с результатами **откроется сама**:

```
...\Avito-bot-stage1-feasibility\probe\probe_output\
```

| Файл | Что это | Чем открыть |
|------|---------|-------------|
| `report.txt` | Сводка: сколько объявлений, какие поля найдены, статистика цен | Двойной щелчок (Блокнот) |
| `items.csv` | Таблица объявлений: ID, название, цена, ссылка, город, дата… | Двойной щелчок (Excel) |
| `page_sample.html` | Очищенная копия страницы для диагностики (без скриптов, аккаунта, телефонов, e-mail) | Нужна, только если я попрошу |

Каждый новый запуск **перезаписывает** эти файлы. Если хотите сохранить результат теста А, скопируйте `report.txt` перед тестом Б (например, в `report_A.txt`).

## Что вы должны увидеть

| Сообщение в окне | Что это значит | Что делать |
|---|---|---|
| `Найдено объявлений: 50` (любое число больше 0), затем `Готово. Файлы результатов…` | ✅ Данные доступны | Пришлите мне `report.txt` |
| `СТОП. HTTP 429…` или `HTTP 403…` или `Страница проверки или блокировки…` | Авито не отдаёт страницу скрипту. Скрипт остановился и ничего не обходил | Это важный результат. Сделайте тест Б, пришлите оба отчёта |
| `Найдено объявлений: 0` и `Объявления не распознаны` | Страница получена, но разметка отличается от ожидаемой | Пришлите `report.txt`, при необходимости попрошу `page_sample.html` |
| `Запрос по ссылке уже был недавно. Подождите ещё N мин.` | Защита от лишних запросов | Подождите или сделайте тест Б: для файла ограничения нет |
| `ОШИБКА: Python не найден` | Python не установлен или не отмечена галочка PATH | Повторите шаг 1 |
| `ОШИБКА: не удалось установить библиотеки` | Нет интернета, или мешает VPN/антивирус | Проверьте интернет и запустите снова |
| `Ошибка защищённого соединения (SSL)` | Антивирус проверяет HTTPS, или неверные дата и время на ПК | Проверьте дату и время; при необходимости временно отключите проверку HTTPS в антивирусе |
| `Нет соединения с avito.ru` | Нет интернета, или Авито недоступен через ваш VPN | Отключите VPN и повторите (через 5 минут) |

## Что прислать мне

Скопируйте и вставьте в чат текст из `report.txt` после теста А и после теста Б.
Если в отчёте написано «Найдено объявлений: 0», напишите, какой браузер вы использовали.

## Альтернатива: те же действия командами (если `.bat` не запускается)

1. Откройте папку `probe` в Проводнике.
2. Щёлкните по **адресной строке Проводника** (где путь к папке), сотрите текст, введите `cmd` и нажмите Enter. Откроется чёрное окно, уже в нужной папке.
3. Вводите по одной строке и нажимайте Enter после каждой:

```
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m unittest discover -s tests
.venv\Scripts\python.exe avito_probe.py
```

- Первая строка создаёт окружение. Она ничего не выводит, это нормально.
- Вторая устанавливает библиотеки. В конце появится `Successfully installed …`.
- Третья — самопроверка без интернета. В конце должно быть `OK`.
- Четвёртая запускает тест. Дальше действуйте как в шагах 4–5 (вставить ссылку или перетащить файл).

Если команда `py` не найдена, используйте `python` вместо `py` в первой строке.
